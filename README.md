# 🚗 PROJETO CONECTIVIDADE

## 📌 Sobre o projeto
Este projeto tem como objetivo apresentar um estudo sobre **conectividade em veículos**, abordando tecnologias, aplicações e impactos no cotidiano.

O trabalho foi desenvolvido como atividade acadêmica seguindo as normas **ABNT**, incluindo planejamento (5W2H) e documentação completa.

---

## 🎯 Objetivos

- Explicar o conceito de conectividade automotiva
- Apresentar tecnologias utilizadas em carros conectados
- Demonstrar benefícios e desafios dessa inovação
- Organizar o projeto com metodologia estruturada (5W2H)

---

## 🧠 Metodologia

O projeto foi estruturado utilizando a ferramenta **5W2H**, que responde:

- **What (O quê?)** → Desenvolvimento de um estudo sobre conectividade em carros  
- **Why (Por quê?)** → Entender a importância da tecnologia automotiva  
- **Where (Onde?)** → Contexto global e aplicações reais  
- **When (Quando?)** → Desenvolvimento durante o período letivo  
- **Who (Quem?)** → Estudante responsável pelo projeto  
- **How (Como?)** → Pesquisa e organização conforme normas ABNT  
- **How much (Quanto?)** → Sem custos significativos
